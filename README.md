# Une Rose Un Espoir - Site Web

Site vitrine et plateforme d'information pour l'association "Une Rose Un Espoir".

## Structure du Projet

Ce projet est organisé en **Monorepo** :

- **`frontend/`** : Application web (Astro + React + Tailwind).
- **`backend/`** : CMS Headless (Strapi + PostgreSQL).

## Stack Technique

- **Frontend** : Astro v5, React, Tailwind CSS, TypeScript.
- **Backend** : Strapi v5.
- **Base de données** : PostgreSQL.
- **Services** : Cloudinary (Images), Resend (Emails).
- **Hébergement** : Vercel (Front), Render (Back).

## Prérequis

- Node.js (LTS recommandé)
- npm ou yarn ou pnpm
- PostgreSQL (pour le développement local du backend, ou utilisation de SQLite par défaut en dev si configuré)

## Installation

Voir les `README.md` spécifiques dans les dossiers `frontend` et `backend` pour les instructions détaillées.
